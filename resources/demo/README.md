# Documentos de ejemplo ficticios

El núcleo incorpora tres extractos de ejemplo en SQLite para probar búsqueda, citas e índice sin acceder a archivos personales. Los números de página son datos explícitos de esta demo, no resultados de extracción. Las rutas demo/ no son archivos personales ni se pueden abrir como originales. PDF/imágenes de prueba reales se incorporarán al hito 2.
